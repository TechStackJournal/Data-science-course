# Data Science Mastery Course
### A Complete Beginner-to-Advanced Curriculum — Python + R, Real-World Analytics Focus

A 16-module, 4-part data science course built around real business scenarios (fraud detection, churn, A/B testing, forecasting through a regime change, support-ticket triage) rather than toy datasets. Every module follows the same six-part lesson format: **CONCEPT → WHY IT MATTERS → SYNTAX REFERENCE → WORKED EXAMPLE → COMMON MISTAKES → PRACTICE EXERCISES**, with hidden hints/solutions.

Start with [`00-curriculum-roadmap.md`](./00-curriculum-roadmap.md) for the full syllabus, pacing guide, and tooling reference.

## Recurring Habits (built in from Module 0 onward)

- **Data cleaning decisions log** — every transformation justified, not just executed
- **Dual deliverable** — a technical notebook plus a plain-English executive summary
- **Metric justification** — never report a metric without explaining why it fits the business problem
- **Leakage audit** — checked in every supervised project, not just Module 8
